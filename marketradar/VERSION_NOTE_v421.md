# v4.21.0 — Adaptive Opportunity Intelligence

v4.21 closes the main v4.20 gaps: opportunity signals, acceptance/revenue learning, source-specific application boundaries, browser recovery, and outcome feedback.

## Judge → Maker cycle
1. Judge compares product goal with executable capability.
2. Maker implements the highest-value missing capability.
3. Tests and audits verify the change.
4. The next pass re-evaluates the remaining gap.

A deterministic 100-pass audit is included in `tools/100_pass_audit.py`.
