# v4.20.0 — Opportunity Intelligence & Action

This release rebalances MarketRadar away from source-count obsession toward the original product outcome: find the best actionable projects, adapt recommendations to the user's learning level, prepare the fastest legitimate application path, and preserve a strict approval boundary for external submission.

## Scope
- Opportunity ranking is a first-class component, separate from source discovery.
- Ranking combines evidence, eligibility, skill fit, difficulty fit, learning value, freshness, competition signals, budget and application speed.
- User learning profile controls recommended project difficulty and supported tracks.
- Red Team / Blue Team are project-selection tracks, not unrestricted offensive automation.
- Application queue prioritizes ready opportunities; actual external submission remains authorization-gated.
- Operational jurisdiction filtering supports explicit country/domain/registration/legal-entity/hosting/IP/location evidence. It does not infer or block people by nationality, ethnicity or religion.
- Windows CI is now runnable on pull requests/main pushes; optional live-search smoke can use a configured SearXNG URL.
