# Autonomous Source Discovery & Policy Automation — v4.18.0

## Problem corrected

The previous design increased the registry but did not independently discover the market. `Active=48` was therefore a configuration property, not evidence that the software had searched the market. v4.18 separates declared sources from automatically discovered sources.

## Runtime chain

```text
Discovery Query Planner
  ├─ open source catalogs
  ├─ regional/language query matrix
  └─ configurable search API (Brave/Bing/Serper)
        ↓
Candidate extraction + host deduplication
        ↓
Evidence provenance + family/region classification
        ↓
SQLite dynamic source registry
        ↓
Source policy monitor
  ├─ homepage + terms/policy/FAQ links
  ├─ policy-search evidence locator
  ├─ Iran ALLOW / BLOCK / UNKNOWN
  ├─ KYC REQUIRED / NOT_REQUIRED / UNKNOWN
  └─ payout/payment/crypto signals
        ↓
LIVE_CONFIRMED / DEAD
        ↓
active global discovery OR blocked/review
        ↓
execution_ready only after strict evidence gate
```

## Important distinction

- `sources.json` is the shipped baseline registry.
- `source_origin=dynamic_discovery` records candidates found by the software itself.
- Dynamic candidates persist in SQLite and survive registry sync.
- A source can be `LIVE_CONFIRMED` and active while still being `iran_eligibility=UNKNOWN`; this does **not** authorize execution.
- Explicit Iran restrictions are automatically moved to `BLOCKED_IRAN`.
- Silence never becomes `ALLOW`, and KYC silence never becomes `NOT_REQUIRED`.

## Search providers

The product does not scrape search-engine HTML. Configure one supported search API through environment variables:

- Brave: `BRAVE_SEARCH_API_KEY`
- Bing: `BING_SEARCH_API_KEY`
- Serper: `SERPER_API_KEY`
- Optional selector: `MARKETRADAR_SEARCH_PROVIDER=auto|brave|bing|serper`

The software remains fully testable without a key through injected providers and lab fixtures.

## Lab evidence

`reports/SOURCE_AUTOMATION_LAB_v4.18.json` is generated by the local test laboratory. It proves the discovery/classification path independently of the production network and includes multilingual Iran-policy cases. It is not presented as live Internet verification.

## Current environment limitation

The current build environment has no outbound DNS/network access. Therefore the production search provider was not allowed to fabricate a live result. The Windows release will perform real discovery only when a supported search provider is configured and the application is online.
